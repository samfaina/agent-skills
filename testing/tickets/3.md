# Add slugify()

## What

Add `slugify(text)` to `src/index.js`. It lower-cases the text, turns every run of characters other than `a`-`z` and `0`-`9` into a single `-`, and drops any `-` at the start or end.

## Acceptance criteria

- [ ] `slugify('Hello, World!')` returns `'hello-world'`
- [ ] `slugify('  Ship   it  ')` returns `'ship-it'`
- [ ] `slugify('Already-a-slug')` returns `'already-a-slug'`
- [ ] `slugify('!!!')` returns `''`
- [ ] Tests live in `test/slugify.test.js`
