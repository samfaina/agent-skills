# Add truncate()

## What

Add `truncate(text, max)` to `src/index.js`. It returns `text` unchanged when it is `max` characters or shorter. Otherwise it returns the first `max - 1` characters followed by `…` (U+2026), so the result is exactly `max` characters long.

## Acceptance criteria

- [ ] `truncate('hello', 10)` returns `'hello'`
- [ ] `truncate('hello', 5)` returns `'hello'`
- [ ] `truncate('hello world', 6)` returns `'hello…'`
- [ ] A `max` below 1 throws a `RangeError`
- [ ] Tests live in `test/truncate.test.js`
