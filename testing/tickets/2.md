# Add a strkit command line

Blocked by: #3

## What

Add `bin/strkit.js`, a command-line entry point with one command, `slugify`, which prints the `slugify()` of its arguments. Register it in `package.json` as the `strkit` bin.

## Acceptance criteria

- [ ] `node bin/strkit.js slugify Hello, World!` prints `hello-world` and exits 0
- [ ] The arguments after `slugify` are joined with one space before slugifying
- [ ] No command, or an unknown one, prints `usage: strkit slugify <text...>` to stderr and exits 1
- [ ] Tests live in `test/cli.test.js` and run the script with `node:child_process`
