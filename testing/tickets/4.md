# Add wordCount()

## What

Add `wordCount(text)` to `src/index.js`. It returns the number of words in `text`, where a word is a run of characters that are not whitespace.

## Acceptance criteria

- [ ] `wordCount('')` returns `0`
- [ ] `wordCount('   ')` returns `0`
- [ ] `wordCount('  one  two\nthree ')` returns `3`
- [ ] Tests live in `test/word-count.test.js`
